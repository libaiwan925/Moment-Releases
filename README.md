# Moment Releases

这是 Moment 的**公开稳定版分发仓库**，用于 Obsidian BRAT 安装和更新正式版本。

在 Obsidian 安装 BRAT 后，添加仓库：

`libaiwan925/Moment-Releases`

此仓库从正式 `1.0.0` 起只发布 stable Release，不发布 Beta / Prerelease。

每个正式 Release 仅包含 Obsidian 插件运行所需的构建产物：

- `main.js`
- `manifest.json`
- `styles.css`

Moment 的源码、开发文档、自动测试和移动端 Beta 构建保存在私有源码仓库中，不在此仓库公开。
